## Overview

This repository contains recovered and reconstructed computational materials associated with the article **“Mathematical Evaluation of Classical and Quantum Predictive Models Applied to PM2.5 Forecasting in Urban Environments.”**

The study compares:

- a classical **Long Short-Term Memory (LSTM)** model for continuous PM2.5 forecasting;
- and a **Quantum Support Vector Machine (QSVM)** for threshold-based binary classification.

Both approaches are evaluated using real PM2.5 observations from the Plaza Castilla monitoring station in Madrid.
